# Logo dan Format PDF SPKL

Logo yang digunakan berasal dari file yang diberikan pengguna:

- `assets/logos/pertamina_patran.png`
- `assets/logos/ptc.png`

Format nomor dokumen:

```text
No.SPKL -          / PPNLK0101 / 2026-S0
No.          /SPKL/PTC/2026
```

Angka tahun tidak tetap. Tahun diambil dari tanggal lembur pada masing-masing halaman.
Hanya bagian bagian nomor urut yang dibiarkan kosong untuk pengisian admin.

Lihat `PDF_OUTPUT_REFERENCE.pdf` atau `PDF_OUTPUT_REFERENCE.png` sebagai acuan tampilan.
