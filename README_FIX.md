# Changelog

## 1.0.1+2 — Kompatibilitas Dart 3.7

- Menurunkan `flutter_lints` dari 6.0.0 ke 5.0.0.
- Menetapkan `go_router` ke 17.0.0 yang mendukung Dart 3.7.
- Menetapkan `share_plus` ke 11.1.0.
- Mengunci versi dependency agar pembaruan otomatis tidak mengambil paket yang membutuhkan Dart lebih baru.
- Menambahkan `FIX_DART_3_7.bat` untuk membersihkan resolver lama dan menjalankan verifikasi.
